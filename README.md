# COS 201 — Week 3 Practical

Programs on Variables, Data Types, Expressions and Input/Output (Java).

## Programs
- `SimpleCalculator.java` — reads two numbers and prints their sum, difference, product and quotient.
- `AverageCalculator.java` — reads three scores and prints the total and average.
- `ItemCost.java` — reads an item name, quantity and unit price, then prints the total cost.

## Requirements
- Java Development Kit (JDK) 8 or later. Check with `java -version` and `javac -version`.

## Compile
```
javac SimpleCalculator.java AverageCalculator.java ItemCost.java
```

## Run
```
java SimpleCalculator
java AverageCalculator
java ItemCost
```

## Sample run (ItemCost)
```
Enter the item name: Notebook
Enter the quantity: 3
Enter the unit price: 450.50
Total cost : 1351.50
```
